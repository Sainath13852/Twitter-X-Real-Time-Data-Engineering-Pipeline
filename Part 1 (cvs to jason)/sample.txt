Title

Predicting Payment Methods Using Supervised Machine Learning on the Amazon Sales & Trading Insights Dataset

Abstract

E-commerce platforms generate large volumes of transactional data every day, and understanding how customers choose to pay can provide useful insight for business operations, fraud monitoring, and payment optimization. This study investigates the prediction of customer payment methods using supervised machine learning techniques on the Amazon Sales & Trading Insights Dataset 2024. The dataset contains structured customer, product, order, pricing, and transaction records, and the target variable is the payment method used in each transaction.

The study treats the task as a multiclass classification problem and compares several commonly used supervised learning algorithms, including Logistic Regression, Decision Tree, k-Nearest Neighbors, Support Vector Machine, Random Forest, and Gradient Boosting. Before training, the data is cleaned through duplicate removal, categorical encoding, feature scaling, and train-test splitting. Model performance is evaluated using accuracy, precision, recall, F1-score, balanced accuracy, and cross-validation accuracy.

The overall aim of the work is not only to identify the most accurate model, but also to understand which approach offers a practical balance between performance, robustness, and interpretability for e-commerce analytics.

Introduction

Online retail systems create a rich record of customer activity, including order timing, location, product category, price, and payment choice. Among these variables, payment method is especially important because it reflects customer preference, transaction convenience, and sometimes risk-related behavior. For a platform such as Amazon, knowing which payment method is likely to be used can help improve user experience, support transaction planning, and guide fraud-related analysis.

This project focuses on the Amazon Sales & Trading Insights Dataset 2024, which contains 10,000 rows and 21 columns of structured e-commerce data. The dataset includes customer, order, product, and pricing attributes, along with the target variable payment_method, which takes multiple classes such as Card, COD, NetBanking, and UPI.

The central idea of this work is to examine whether transaction-level information is sufficient to predict the payment method used by a customer. To answer this, the study applies a supervised machine learning workflow and compares several classification models. The analysis is designed to be practical as well as comparative, so that the final model recommendation is based on both predictive quality and usability in a real business setting.

Related Work / Background

Supervised learning has been widely used in classification tasks where the target variable belongs to a finite set of categories. In e-commerce settings, classification models are often used for customer segmentation, churn prediction, fraud detection, recommendation systems, and transaction analysis. Payment-method prediction fits naturally into this broader category because it involves learning patterns from historical transaction records and assigning a category to new observations.

From a methodological point of view, the models selected for this project cover a useful range of classification behavior. Logistic Regression gives a strong baseline for linear decision boundaries. Decision Trees capture non-linear rules and are easy to interpret. k-Nearest Neighbors relies on similarity between observations. Support Vector Machines can be effective in higher-dimensional feature spaces. Random Forest and Gradient Boosting represent ensemble methods, which are often stronger in tabular classification problems because they combine multiple learners and reduce instability. This model set is consistent with the comparison design described in the proposal.

A further reason for including preprocessing comparison and cross-validation is that real-world tabular data rarely behaves ideally. Categorical variables, duplicated records, and uneven class distributions can affect results, so evaluating models under more than one metric gives a more realistic picture of performance. The proposal explicitly emphasizes robustness, interpretability, and practical trade-offs rather than accuracy alone.

Methodology

The project follows a full supervised machine learning workflow. The dataset is first collected from Kaggle and imported into Python using pandas. After loading, the data is cleaned and prepared for modeling. The proposal states that preprocessing includes removal of duplicate records, removal of constant columns, missing-value handling, encoding of categorical variables, and scaling of numerical variables.

Categorical features are transformed using one-hot encoding, while numerical variables are standardized using StandardScaler. The dataset is then split into training and testing sets using an 80/20 split, with stratified sampling to preserve the class distribution.

After preprocessing, the study trains and compares six machine learning algorithms: Logistic Regression, Decision Tree Classifier, k-Nearest Neighbors, Support Vector Machine, Random Forest Classifier, and Gradient Boosting Classifier. Model evaluation is carried out using several classification metrics so that performance can be assessed from multiple angles rather than relying on a single measure.

A final stage of the workflow involves cross-validation, feature importance analysis, and a comparative recommendation. This is important because the project is not only trying to find the best-performing model, but also the most practical one for deployment and interpretation.
